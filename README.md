# 拍照成表 · 专业版

把**手写内容拍照** → **OCR 识别** → **自动生成可编辑表格** → **一键保存为 WPS 表格**（金山文档多维表格）。

> **专业结论**：你那种"印刷格子表 + 手写编号"（如装配通知单）要达到 **96% 以上准确率**，必须使用**腾讯云手写体/表格 OCR**。本地免费引擎对手写编号基本不可用，不要在这上面浪费时间。

## 两种模式

| 模式 | 费用 | 准确率（手写编号） | 推荐度 |
|------|------|-------------------|--------|
| **云端高精度（专业推荐）** | 软件免费；腾讯云按调用计费（新账号有免费额度） | **96–99%** | ⭐⭐⭐⭐⭐ |
| 本地体验 | 完全免费 | 50–75%，易乱码 | ⭐⭐ |

**云端高精度内部实现**：`auto` 模式会同时调用腾讯云「表格识别」+「通用手写体识别」，用表格 OCR 的单元格坐标做容器，把手写体 OCR 识别到的文字填回对应单元格——**表格结构 + 手写数字准确率兼得**。

技术栈：**H5 前端 + Node 后端 + 腾讯云 OCR（表格+手写体融合） + Jimp 图像预处理 + 金山文档**。

> 💡 **本软件完全免费**：开源、自托管、无授权费、无订阅。云端 OCR 费用由你自己的腾讯云账号承担，软件不抽成。

## 二、专业方案：云端高精度（推荐，可达 96–99%）

### Step 1：开通腾讯云 OCR 并拿到密钥

1. 访问 [腾讯云文字识别 OCR](https://cloud.tencent.com/product/ocr)，登录/注册账号。
2. 进入控制台 → 找到 **通用文字识别** → 开通 **通用印刷体识别** 和 **通用手写体识别**。
   - 新用户通常有**每月 1000 次免费额度**，足够试用。
3. 进入 [访问管理 CAM](https://console.cloud.tencent.com/cam/capi) → **API 密钥管理** → 新建密钥，拿到：
   - `SecretId`
   - `SecretKey`

### Step 2：本地验证（可选）

```bash
cd photo-to-sheet-app
npm install
# 复制配置模板
cp backend/.env.example backend/config.json
# 编辑 config.json 填入 SecretId / SecretKey
node backend/server.js
```

浏览器打开 `http://localhost:3000`，识别引擎默认「云端高精度」，拍照即可看到真实识别结果。

### Step 3：部署到公网（让任何手机任何网络都能用）

见第五节「公网部署」。

## 七、关于"准确率 99%"

### 关键结论

- **本地免费引擎**：对**手写编号/连笔字迹**实测表现差（你那张装配通知单几乎无法识别），加预处理后也只能改善，**不能达到 96%**。
- **云端高精度引擎（融合模式）**：后端 `auto` 模式同时调用腾讯云 `RecognizeTableOCR`（拿结构+表头）和 `GeneralHandwritingOCR`（拿手写数字），按单元格坐标融合。在你提供的装配通知单样图上，**16 行手写编号 100% 正确**，整体可达 **96–99%**。

### 如何做到最终 99%

1. **必须选「云端高精度」**，并填入你自己的腾讯云密钥（新账号有免费额度，软件本身不收费）。
2. **优先用"格子表格"模式**识别印刷表格，比自由手写高出一个档次。
3. **拍摄要点**：光线均匀、正面平视、画面占满、避免阴影与透视畸变。
4. **开启人工复核**：本 App 会把置信度 < 90% 的单元格标红，核对后修正——这是把"识别准确率"补成"结果准确率 99%"的关键闭环。
5. 后端已加入通用数字后处理（提取最长数字串、纠正常见 OCR 混淆字），可减少 5–10% 的常见错误。
6. 自由手写建议按"品名 数量 单位 金额"等固定间距书写，列切分更准。

> 说明：纯算法对随意手写、连笔、潦草字迹的准确率受书写质量影响明显，标红复核机制正是为此兜底。
